# Aviadilo version 1 contracts

Schemas use JSON Schema draft 7. `cases.json` is the same accept/reject corpus for Python and TypeScript; both also enforce related-field geometry constraints. Unknown protocol versions fail explicitly. Protocol objects are closed; card configuration and its panels preserve future fields during unrelated edits. Configuration must include `schema_version: 1` and card `type`; normalization supplies the saved defaults.

Coordinates are WGS84 degrees, including valid zero latitude/longitude. Viewport south must be less than north; west greater than east denotes antimeridian crossing. Wind grids use EPSG:4326 cell centres, eastward columns and north-to-south rows with negative latitude spacing. Grids cannot wrap the antimeridian, exceed 4096 cells, or extend outside coordinate bounds. U/V are true east/north metres per second with paired null masks, never encoded no-data sentinels. SI quantities have explicit suffixes. Course is direction of travel, not heading. Unknown altitude and ground state remain null and independent; zero altitude never implies ground.

UTC timestamps require a real calendar date and a trailing `Z`. All numbers must be finite. Aircraft IDs are provider-qualified and unique per snapshot. Aircraft latitude/longitude are both known or both null. Frame IDs are opaque and unique; they are not timestamps or URLs.

Card radius/extent values are metres with separately saved km/mi/nmi display preferences. Integration aircraft radius has a conservative 250 nmi (463,000 m) schema ceiling; provider adapters must enforce any stricter capability. Provider pacing settings can only lower the shipped request ceilings. Cache-clear and diagnostics are actions, not persisted configuration values. Backend memory (64 MiB), heartbeat (20 s) and lease (60 s) are fixed policy exposed through info. Card people selection defaults empty; people enabled with no selections renders none. Runtime transport validation/authentication is slice 3 work.

Generate TypeScript declarations with `npm run contracts:generate`. Schemas are the source of truth, not hand-edited generated TypeScript. Python runtime types and geometry helpers live entirely inside the integration. Tests load schemas from this directory; installed Python does not depend on this development directory or jsonschema. The frontend config validator is bundled into its generated ES module by Vite.
