# Radar slice API

`RadarController(client, {decode?})` accepts the `loadTile(tile, signal?)` / `releaseTile(url)` subset of AviadiloClient. Call `configure(radarConfig)`, `receive(SnapshotEvent)`, `setViewport(Viewport)`, `setVisible(boolean)`, and finally `dispose()`. `subscribe(listener)` immediately emits `RadarView` and returns an unsubscribe function. `view()` reads the same state. `latest()`, `play(boolean = true)` and `seek(frameIndex)` control playback; these actions never alter aircraft/people time. The card still owns client selection, connection state and visibility/demand. Pass current manifest events after the client applies each subscription revision.

`RadarLayer(controller).attach(leafletMap)` creates the noninteractive radar canvas and supplies viewport updates. `dispose()` removes listeners/canvas and hides the controller, which aborts tile work and clears buffers. Reattachment is supported; only the controller owner calls its terminal `dispose()`. Neither API fits or recenters the map. `radarTimeline(view, controller)` and `radarLegend(view)` return Lit templates. `radarControls(config, edit)` is the graphical editor helper; the callback applies one config path.

Latest loads first. Static latest mode does not preload history; looping preloads at most one adjacent advertised frame. Up to three frames and 32 tiles/frame (24 MiB decoded images) are retained; the canvas reserves at most 8 MiB. Extremely large viewports use a coarser native tile grid. Native overzoom is local enlargement, not added physical detail. RainViewer caps z7, MRMS z7 (~1 km pixels in California), KSOX z9 (~250 m display sampling, with variable range/azimuth resolution). NOAA does not publish a native slippy zoom: those two values are conservative sampling caps.

RainViewer uses Universal Blue scheme 2, smoothing on, snow coloring off (`2/1_0`). `rainviewer-colors.json` is the first/rain table's exact Universal Blue column from https://www.rainviewer.com/files/rainviewer_api_colors_table.csv retrieved 2026-09-07, supplied by the orchestrator. NOAA `noaa-legend.png` is the exact public-domain radar_reflectivity WMS legend from the frozen 2026-09-06 Claremont spike. Both are bundled, with no runtime legend fetches. NOAA envelope rectangles are not per-pixel validity masks; RainViewer has no per-pixel coverage contract.

Metadata is collected only while demanded: RainViewer every 300 seconds, NOAA every 120 seconds. Successful poll cadence survives a rapid hide/reopen, while the last snapshot replays immediately. Cache-Control/ETag/Age govern the separate HTTP cache. NOAA does not advertise a capabilities generation timestamp, so its `generated_at` is the original successful metadata receipt time (preserved across cached replay/304); `frames[].time` is always the exact advertised source time. An advertised newest frame older than 15 minutes is stale even when metadata receipt is recent. Empty successful histories mean unavailable imagery, never dry weather. Manual frame selection survives refresh while its frame remains within the configured history; Latest explicitly follows the newest advertised frame.
