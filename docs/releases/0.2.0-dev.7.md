# Aviadilo 0.2.0-dev.7

People/device markers and **You are here** now spread apart when they overlap, with connector lines back to their real locations. The reference pin gets priority to stay at its true position when possible. Locations, accuracy circles and automatic-fit bounds are unchanged by these visual offsets.

For counted clusters instead, enable **People → Group overlapping markers**. Click, tap, Enter or Space expands a group; Escape or a map-background tap collapses it. Counts include the reference pin when present. Large groups on small maps use a scrollable member panel so every marker remains accessible.

The new **Map → Map view mode → Auto-fit people/devices** option fits only the filtered people/device locations. Aircraft, the reference pin and separately included zones do not enlarge those bounds. Manual pan/zoom pauses fitting until Recenter or the configured idle return. Existing Home area and Auto-fit visible items modes remain available.

Select **v0.2.0-dev.7** in HACS under **Need a different version? → Release**, restart Home Assistant and reload dashboards. Individual spreading is the default; grouping is optional. This is the final refinement prerelease for hands-on assessment before normal 0.2.0; v0.1.0 remains the normal update channel.
