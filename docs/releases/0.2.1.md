# Aviadilo 0.2.1

This normal release promotes the confirmed 0.2.1-dev.3 build without changing its functionality.

- Cached basemap tiles can load while new tiles wait for the provider, with fair queuing across kiosks sharing an HA login.
- Visible tiles recover automatically from temporary capacity and connection failures, respecting retry delays and cancelling work no longer needed.
- Fresh basemap images can be reused for up to one hour after leaving a map, within existing memory and provider-freshness limits.
- Originally independent household icons get priority at their true positions; relocated icons use the remaining space. Thicker dark connectors with light outlines make their true locations easier to follow on both map themes.

Use normal HACS **Update**, restart Home Assistant and reload dashboards. Upgrades preserve integration settings, dashboards and shared caches. New users can follow the [quick-start guide](https://github.com/bishopdynamics/aviadilo/blob/main/docs/quick-start.md); add the repository to HACS as an **Integration**.
