# Aviadilo 0.2.0-dev.3

Fixes blank basemaps for ordinary and read-only Home Assistant kiosk users. The previous frontend subscribed directly to `aviadilo/assets_changed`, which Home Assistant restricts to administrators. That refusal stopped asset initialization before any map tile request.

Aviadilo now provides a dedicated authenticated subscription for its cache-generation metadata. Cache clearing, reconnects and shared tile caching continue to work with the user's existing permissions. MQTT configuration and administrator access are not required.

Select **v0.2.0-dev.3** in HACS under **Need a different version? → Release**, restart Home Assistant and reload kiosk pages to load the matching frontend. Existing settings are retained. This prerelease leaves v0.1.0 as the normal update channel.
