# Aviadilo 0.2.0-dev.4

Adds a default-enabled **You are here** reference icon. It marks the card's configured map anchor—Home Assistant home by default—and stays at that geographic location when you pan.

Turn it off with **Show “You are here” marker** in Map settings. It is independent of the aircraft, radar, wind and people layers. The marker uses the existing map reference rather than measuring the viewing device's GPS location, and adds no provider requests.

Select **v0.2.0-dev.4** in HACS under **Need a different version? → Release**, restart Home Assistant and reload the dashboard. Existing kiosk permissions and settings are retained. This prerelease leaves v0.1.0 as the normal update channel.
