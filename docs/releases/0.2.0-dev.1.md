# Aviadilo 0.2.0-dev.1

This development candidate adds light, dark and Home Assistant themes, one selectable wind display with a configurable color, and a quieter kiosk card. Layer buttons, Recenter, the optional aircraft list, selection popups and visible source credits remain available. Weather settings move into the visual editor; problems appear through a compact indicator with read-only details.

Existing dashboards migrate in memory to card configuration version 2. A normal editor save persists that version. Legacy combined wind markers and particles become **Particles**; legacy wind styles that drew nothing become **Arrows** while preserving the Wind layer toggle. Reduced motion displays static arrows without changing a saved Particles setting.

In HACS, explicitly select **v0.2.0-dev.1** under **Need a different version? → Release**. Restart Home Assistant and reload dashboard browsers before editing or saving card settings: an old cached frontend cannot read version-2 card configuration. Untouched version-1 dashboards remain supported after the upgrade. Integration settings and the shared cache are retained.

This is a prerelease. It does not replace v0.1.0 as the normal HACS release.

Home Assistant recreates editor previews after settings changes, so temporary playback or selection can reset. Saved settings and the shared data cache remain available.
