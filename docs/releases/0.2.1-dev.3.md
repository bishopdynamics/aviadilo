# Aviadilo 0.2.1-dev.3

Independent household icons now get priority at their true map positions. When several people overlap, relocated icons use the remaining space instead of pushing an unrelated person's icon away. This also applies when optional groups are collapsed or expanded. Existing map-edge and overflow handling remains.

Relocated person/device and **You are here** icons now have thicker dark connector lines with a light outline, making their true locations easier to follow on light and dark maps. The lines remain noninteractive.

Real coordinates, accuracy circles, filtering and automatic-fit bounds are unchanged. This build includes the one-hour basemap cache from dev.2.

Select **v0.2.1-dev.3** in HACS under **Need a different version? → Release**, restart Home Assistant and reload dashboards. Normal **v0.2.0** remains Latest during testing.
