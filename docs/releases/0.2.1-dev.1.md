# Aviadilo 0.2.1-dev.1

This prerelease improves basemap loading when several dashboards or kiosks share a Home Assistant login.

- Cached tiles can load while new tiles are waiting for the map provider. A bounded queue schedules competing requests instead of immediately rejecting an ordinary burst.
- Visible tiles automatically retry temporary capacity and connection failures with controlled backoff and Retry-After support. Moving away cancels work that is no longer needed.
- Fresh basemap images remain available for up to ten minutes after leaving a map, so returning can reuse them without another tile request or image decode. Retention is bounded and rechecks the current integration/cache identity before reuse.

Provider pacing is unchanged. The retained navigation cache contains basemap tiles only; household photos keep their existing permission and cache rules.

In HACS, select **v0.2.1-dev.1** under **Need a different version? → Release**, restart Home Assistant and reload dashboard browsers. Settings and the shared server cache are retained. Normal **v0.2.0** remains Latest while this change receives hands-on testing.
