# Aviadilo 0.2.0-dev.2

The Map settings now include **Show layer buttons** and **Auto-size height to page**.

Turn off Show layer buttons for fixed saved layers. Recenter keeps its separate checkbox, so you can hide both for a clean map. Required source credits and the compact problem indicator remain available.

Auto height fills the remaining visible page below the card and adapts to window/layout changes. Fixed pixel height remains the default and is retained when you switch modes. A minimum map height keeps the map usable when other card content fills the screen; list-only cards keep their natural height.

Select **v0.2.0-dev.2** in HACS under **Need a different version? → Release**, restart Home Assistant and reload the browser. Existing configurations keep their current controls and fixed height until you enable the new options. This prerelease leaves v0.1.0 as the normal update channel.
