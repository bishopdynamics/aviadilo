# Aviadilo 0.2.0-dev.6

People settings now accept **person** entities as well as existing **device_tracker** entities. Person suggestions come first, letting Home Assistant choose among that person's associated trackers. Existing saved selections and row preferences are retained; choose the matching person entity in the editor when you want to switch.

Like HA's stock map, Aviadilo uses a person's coordinates when available, otherwise the first reported active zone with a usable location. Zone fallback is labelled as a zone location with GPS age unknown and no GPS accuracy circle. Radius filtering, freshness and location warnings use the same resolved point. Person photos use the existing authenticated, permission-checked image path.

Select **v0.2.0-dev.6** in HACS under **Need a different version? → Release**, restart Home Assistant and reload dashboards. Then open **People → Selected people and device trackers**, replace the affected device tracker with its **person.…** entity and save. Normal v0.1.0 remains the default update channel.
