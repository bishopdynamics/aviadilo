# Aviadilo 0.2.0-dev.5

Aircraft now use recognizable icons for airplanes, helicopters and the other reported aircraft kinds. Icons retain the configured size/color, course rotation and stale styling; a question-mark badge identifies missing course data.

In **Aircraft → Aircraft types**, choose which groups appear. All are enabled by default; leave only **Helicopters** checked for a helicopters-only map and list. Filters also apply to automatic-fit candidates and clear a selection/trail when its type is hidden. **Unknown** covers missing or unrecognized categories. Classification uses the existing reported category, so it does not add provider requests or infer type from speed, altitude or model names.

Select **v0.2.0-dev.5** in HACS under **Need a different version? → Release**, restart Home Assistant and reload dashboard browsers. Existing settings and kiosk permissions are retained; v0.1.0 remains the normal update channel.
