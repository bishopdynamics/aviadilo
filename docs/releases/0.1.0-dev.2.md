# Aviadilo 0.1.0-dev.2 — candidate release notes

Status: local development candidate. No tag or release has been published by the slice 8 session. Publish only after the remaining HACS delivery checks are resolved.

The Aviadilo card combines aircraft, radar, wind and existing household `device_tracker` entities in one map. The companion integration shares collection, provider pacing and bounded caches across viewers. One HACS Integration ZIP includes the backend and matching compiled card.

- Aircraft markers, selectable list and details, with distance/altitude/age filters and local selection trails.
- RainViewer, NOAA MRMS and KSOX radar history, playback, timestamps, coverage messages and source legends.
- DWD ICON-global wind arrows, barbs and bounded local particles, with reduced-motion support.
- Household radius filtering before rendering or fitting, manual view control and recentering.
- Full graphical card editor and graphical shared integration settings. Picker/editor previews use synthetic data.
- Automatic versioned card loading, reconnect/reload recovery, and cleanup when cards are hidden or removed.

Compatibility baseline: Home Assistant 2026.9.1. Local browser checks use Chromium 151.0.7922.34 and 153.0.8010.12 on Linux. The user's physical tablet remains untested.
