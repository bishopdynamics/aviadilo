# Aviadilo 0.2.1-dev.2

Fresh basemap images can now be reused for up to **one hour after leaving a map**, extended from ten minutes. Returning during that window can reuse the decoded tiles without another tile request.

The existing 32 MiB / 128-entry memory limit, provider expiry, cache-clear handling and user/connection checks remain in force. The longer window does not keep expired tiles fresh, retain household photos or generate background requests.

The tile-streaming fixes from dev.1 are user-confirmed. Select **v0.2.1-dev.2** in HACS under **Need a different version? → Release**, restart Home Assistant and reload dashboards. Normal **v0.2.0** remains Latest during testing.
