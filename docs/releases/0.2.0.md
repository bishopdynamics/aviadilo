# Aviadilo 0.2.0

This release brings the tested kiosk refinements to the normal HACS update channel. Functionality is unchanged from 0.2.0-dev.7.

- A cleaner map with optional layer buttons, automatic page height, light/dark/HA themes and an optional **You are here** pin at the configured map anchor.
- Wind arrows, barbs or particles with configurable color. Healthy weather details live in the graphical editor; a compact map indicator explains loading failures or unavailable data.
- Distinct airplane, helicopter and other aircraft-category icons, with checkboxes to show only the types you want.
- Home Assistant `person` entities alongside existing `device_tracker` selections, including active-zone fallback and household photos.
- Overlapping household icons spread apart by default, with connectors to their true locations. Optional counted groups expand by mouse, touch or keyboard.
- **Auto-fit people/devices** fits only the locations remaining after your people filters, so distant travellers and aircraft do not pull that view away.
- Reliable basemap and photo loading for regular and read-only kiosk users through authenticated asset subscriptions.

Use HACS **Update**, restart Home Assistant and reload dashboard browsers. Upgrades from 0.1.0 and 0.2.0 prereleases retain integration settings, dashboards and shared caches. Existing card settings migrate when loaded; saving through the editor stores version-2 configuration. Reload all dashboard browsers before editing these settings.
